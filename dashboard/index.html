How to produce new results (rerun the experiments) 
python scripts/eval_routing.py            # main experiment (needs the LLM; resumes from cache; --no-llm re-analyses cached answers)
python scripts/eval_retrieval.py --methods bm25,dense,hybrid --top-k 10 --repeat 3
python scripts/eval_policy.py             # earlier corpus-coverage experiment
python scripts/bench_latency.py           # repeated latency benchmark

Each run writes a new timestamped folder; older runs are kept. Then click Reload.
